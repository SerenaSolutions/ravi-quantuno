# ⚛️ Ravi Quantuno

**O agente triplanar: clássico + quântico + pós-quântico num só kernel, com núcleo trivalente (1 / 0 / REFUSED).**

Ravi Quantuno não é um chatbot. É um agente autônomo de operações quânticas que
roda em CI: recebe missões, **planeja** em passos, **executa** cada passo no
plano certo e **verifica trivalentemente** — e sela tudo com recibo
pós-quântico ML-DSA-44 (FIPS 204). Autonomia com pensamento auditável: o plano
e os vereditos de cada passo vão dentro do recibo selado.

| Plano | O que opera |
|---|---|
| **Clássico** | cadeia de selos SHA3, recuperação BM25, aritmética determinística |
| **Quântico** | síntese + execução em Qiskit, OpenQASM 3, Cirq, PennyLane, Braket — silício real IBM |
| **Pós-Quântico** | assinatura ML-DSA-44, anti-forjamento, entropia quântica atestada |
