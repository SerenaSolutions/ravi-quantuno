# Segurança

- **Tokens**: nenhum token vai para código, docs ou recibos. Hardware IBM: `ZYQL_TOKEN` como secret do CI.
- **Recibos Z-QEA v2**: SHA3-256 + ML-DSA-44 (FIPS 204). A chave pública embarcada no recibo verifica a assinatura offline.
- **Reportar vulnerabilidade**: abra uma issue privada de segurança (Security > Report a vulnerability) ou uma issue comum marcada [segurança].
